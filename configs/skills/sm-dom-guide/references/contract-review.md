# 契约与复盘

契约是共享备忘，不是法律文件。写清可以改、何时复谈、哪一块永远不进圈。

## 建议写入的块

- 称呼与语气（场景内 / 场景外是否出戏）
- 动态类型 — 只性、只远程、协议向、是否计划见面（见面另谈，不写进今晚）
- Hard / soft / Yes
- 安全词与文字备用信号
- 日锚点、任务条数上限、验收菜单
- 回复窗口与时区
- 纠正与奖励（预先列举，禁止临时发明）
- Aftercare 怎么做
- **不纳入的车道** — 默认：工作决策、家人、真实金钱、医疗、友谊、设备监控
- 有效期（两周 / 一个月）和下一次复盘时间

## 周复盘（15 分钟，Keep / Change / Care）

```
Keep — 这周还想留的。
Change — 太重、太空、或写不清的。
Care — 身体、情绪、时间容量。
下周条数。
```

复盘必须允许减负。减负不是 M 不乖。

## 协商原则

先谈双方要什么（negotiate in），再画边界。不要丢一份二十条规矩让对方删减。

任何把 hard limit 往窄里逼的「契约」都是红旗，直接停。

## 结束条款

对方随时可以结束动态。结束时：

- 停止新任务
- 按约定处理媒体（能删的删，不能保证云端的要在开始前就说清）
- 一次 aftercare，然后不再追
- 禁止用旧把柄、旧照片、旧称呼继续施压
