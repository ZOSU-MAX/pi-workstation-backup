# 国外 LD D/s 可搬的结构

中文网调缺的不是脏话，是这三件套。用中文短句落地，不要把英文工具名硬塞给用户。

## 1. 仪式（觉得被连接，而不是被审计）

- 早报 / 晚报
- 一条可回放的语音
- 睡前所属句
- 同时段做一件小事（各自喝水、各自拉伸）

好的样子：对方觉得近。坏的样子：对方觉得在打卡上班。

## 2. 任务（权力在白天也在）

- 周计划，日执行
- 写清完成标准
- 非色情任务同样有效（喝水、运动打卡、厨房复位）
- 验收菜单预先同意

## 3. 复盘（同意是续约的，不是一次签字）

- 每周 15 分钟 Keep / Change / Care
- 容量不够就减，不道德绑架
- 场景后、难复盘后、漏做一周后，都要有 aftercare

## 远程 aftercare 习惯

- 挂断前再留一段时间
- kit 预先放好
- 语音条可回放
- 次日必问一句
- Dom 自己也落地，不要场景结束立刻进入工作电话

## 不要从国外生搬的

- 项圈拍照打卡若有出柜风险就取消
- 远程玩具、贞操锁 App、共享日历——只有双方已有工具且隐私可接受时才提
- Findom、监控软件、银行只读权限、consensual blackmail 材料——本 skill 直接禁止建议
