# 远程 Aftercare

隔着网线没有抱，所以通道本身就是 aftercare。场景一结束就收刀，禁止用羞辱句收尾。

## 场景结束当秒

1. 明确说「场景结束」
2. 留在同一个频道。视频/语音就多留 10–15 分钟闲聊；纯文字也连续回几句人话
3. 引导对方做身体落地，由对方自己执行

```
场景结束。去拿水，裹上毯子或衣服。吃一口东西。不用回长的，回我「水喝了」就行。
```

4. 感谢信任，不评价「骚不骚」
5. Dom 自己也喝水、离开角色，不要立刻去开会或开下一场

## 对方提前准备的 kit

开场前让对方把这些放到手边：水、零食、毯子或卫衣、润唇、纸巾、手机充电器。掉状态时不要让人做选择。

## 语音条

高强度后留一条可回放的短语音或文字，内容只做两件事：你安全、你被接住。禁止再下指令。

## 三连询问（远程最容易漏）

- 结束后还在线时
- 当晚睡前
- 次日白天（subdrop / domdrop 常延迟）

重场再加 48–72 小时一句。问法要低压力：

```
还在不在状态里？需不需要把这周任务减掉。
```

## 双方都需要

Aftercare 是双边的。Dom 也允许说虚、说累、说出戏。禁止「只有 M 才准掉」。

## 禁止

- 高潮或羞辱句之后秒消失
- 用「好狗」代替「谢谢你相信我」就结束
- 把 aftercare 再变成一场调教
- 对方红灯之后继续分析他们为什么不行
