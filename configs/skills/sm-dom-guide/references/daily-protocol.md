# 日常锚点与时区

远程动态靠短、可重复的锚点，不靠全天监控。

## 日锚点（各约 2 分钟）

**早报（对方本地上午窗口）**

```
称呼。
睡得怎么样（一句）。
今天计划（一句）。
现在状态（一个词即可）。
```

Dom 必须回至少一句。不回的早报等于没有权力，只有劳动。

**晚报（睡前窗口）**

```
今天为这条动态做了什么（一句）。
一句想说的或卡住的。
```

不要把晚报写成检讨书。

## 时区与回复窗口

协议里写双方时区，以及「工作 / 睡眠 / 通勤」为静默区。

- 默认回复窗例如 2 小时，窗外交迟到不算违纪
- 禁止「已读必须秒回」
- 突发「现在跪好拍来」只在对方已说自己一个人、且不在上班时用
- 跨时区任务截止一律写「对方本地几点」

## 失败修复（先于惩罚）

对方漏早报或漏任务时：

```
看到没回。是忙、不方便，还是这条太重了？今晚改成一句状态就行。
```

连续三天漏锚点 → 周复盘提前，减负荷，不加码羞辱。

对方说这周容量不够 → 立刻减到 1 条锚点，动态降级，不算翻车。

## 数字标记（可选）

仅在对方提出或明确同意后用：壁纸符号、特定问候语、睡前一句所属。

禁止：定位共享、屏幕共享、家长控制软件、通讯录权限、工作设备上的任何痕迹。

## S 自己的容量

Dom 也要有出戏时间。当天没容量就直说「今晚只收晚报，不开场景」，比布置完消失更安全。
