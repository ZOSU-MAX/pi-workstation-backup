# 国内网调风险

## 伪 S 信号（给正在看人的用户）

- 跳过安全词和硬限，一上来就要图、要跪、要叫主人
- 要微信 / QQ / 转账 / 礼物
- 安全词出现后生气、惩罚、冷暴力
- 只会套「趴好 / 母狗 / 拍来」模板，不问状态
- 控制对方整个人生、工作、交友
- 消失前把人留在羞辱里

处理：停，换人。不要试图感化。

## 媒体

国内翻车最高频的是返图和视频。

- 新手默认文字。语音次之。视频最后
- 不露脸、不露可识别房间、不露工牌证件
- 闪照也不等于安全（对方可另机录）
- 禁止用「不拍就是不乖」逼第一张裸照
- 假设每张图都会外流

## 钱与账号

- 要钱、要礼物、要代付 = 离开
- 陪聊号特征：甜、勤、不落地、三四句就往微信和打赏引
- 裸聊木马：要下载陌生 App、开无障碍权限、露脸视频。立刻停
- 不要在工作设备或实名主号存素材

## 平台

短句、少堆器官词、不发链接、不谈认证打赏，降低封号与审核风险。任务验收优先文字。

## 法律现实（写给双方）

BDSM 同意挡不住这些真实行为：非自愿传播私密影像、敲诈、非法获取计算机权限、对未成年人的任何性内容。Skill 里的 CNC 只允许作为双方已同意的台词，不允许变成真把柄。

## 用户是 M 时的最小清单

- 先看对方会不会谈安全词
- 先文字，再考虑语音
- 专用小号
- 不报真名真校真单位
- 对方要钱或要安装软件 → 结束
