# 网调任务设计

## 四件套（每条任务都写全）

1. **任务** — 一句说清做什么
2. **完成标准** — 怎样算做完，禁止「好好表现」这种空话
3. **截止** — 对方本地时区的钟点或「今晚睡前」
4. **验收** — 预先同意的一种即可，并准备备选

验收菜单（按侵入性从低到高，默认选低的）：

- 文字回执（做了 / 没做成 + 一句状态）
- 短语音（不露身份信息）
- 无脸照片（姿势、书桌、水杯，不含可识别背景）
- 信任即可（高信任、低风险任务）

同一周至少提供两种可接受的验收，避免「不拍就不算」。未协商的验收不准临时加码。

## 一周负荷

- 新关系或工作周 — 2 条
- 稳定后 — 3–5 条
- 禁止 20 条日常清单。任务是提醒对方想起你，不是审计人生

把任务分成三条车道，一周里至少有一条非色情：

- **自顾** — 喝水、睡眠、拉伸、按时吃饭
- **服务** — 为 Dom 整理一段笔记、读指定短文、准备下次场景的工具
- **头空间** — 姿势练习计时、一句晚报、日记三行

性任务单独标「可选 / 仅私人空间」。对方在公共场合或家里有人时，性任务自动挂起。

## 写法模板

```
任务：今晚 23:00 前复位厨房。
完成：台面擦干、水槽清空、碗进洗碗机或沥干。
截止：对方本地 23:00。
验收：文字「厨房好了」+ 一句身体状态。不想拍照可以不拍。
```

```
任务：早报。
完成：四行——称呼、睡眠、今日计划一句、此刻情绪一个词。
截止：对方本地 10:00 前。上班可延到午休。
验收：那条消息本身。
```

## 惩罚与漏做

漏做先当物流问题，不当人格问题。

1. 问原因（班、家人、掉状态、任务写不清）
2. 修任务或改截止
3. 只有重复且对方仍在动态里，才用事先同意的象征性纠正（写十行复盘、取消当晚高潮许可、暂停一条娱乐任务）

禁止用这些当惩罚：不理人、突然加暴露任务、要钱、要真脸、公开处刑、威胁外传。

## 布置时的口吻（给 S 用户可复制）

短，带完成标准，留退路。

```
今晚只一件。23点前把厨房复位，台面干、水槽空。回我「好了」就行。家里不方便就改说明早。
```
