# 输出模板

按用户要的长度选短版或全版。不要两份都倒一遍。

## 短版（默认，对话少于 20 轮或用户说「看一眼」）

```
一句话人设：
兴趣浓度：x/10（升温|横盘|降温）
她把你放在：
现在最可能的解释：
不要做：
下一句可发送：
1.
2.
还缺的证据：
```

## 全版

```
# 她的画像（日期 / 样本区间）

## 一句话人设
20 字内。像外号，不像鉴定书。

## 样本与置信度
- 轮次、跨度、渠道
- 总置信度：低 / 中 / 高
- 哪些维度是硬证据，哪些是推测

## 沟通操作系统
- 长度、启动权、标点、时间纹理
- 和她说话最省力的方式（一句）

## 关系定位
主定位 + 次定位。各挂一条原话。

## 兴趣浓度
分数、趋势、最近一次加强/削弱的行为。

## 自我与价值观
她反复主动提起的 3 件事。她比较他人时用的尺子。

## 依恋工作模型
安全 / 焦虑 / 回避 / 混合。置信度。调节手段。

## 边界
守住的 / 被踩后的反应。

## 性与权力
有证据才写。否则一行「样本未出现」。

## 红旗
2–5 条，原话 + 为什么算旗。

## 绿旗
2–5 条，原话 + 为什么算旗。

## 三种假说
- 最善意：
- 最可能：
- 最谨慎：

## 行动
- 下一句（2 条可复制，匹配她的长度和幽默）
- 本周只推进一件事（选：维持节奏 / 要一个具体窗口 / 停手）
- 不要做的 3 件事

## 本轮修正
若是迭代：哪些旧结论被加强或推翻。
```

## 写回复稿时

先用一句话点明策略（陪聊、降温、要窗口、澄清定位），再给句子。

句子规则：

- 不超过她最近三条消息的平均长度
- 只带一个问题或不带问题
- 不复述她已经拒绝的媒介
- 不用「嘿嘿」「呢呢呢」去模仿撒娇，除非她先用这个操作系统
- 不在同一条里又撩又审又约

给「可发送」和「备选更收」两条就够，不要一次五个风格。
