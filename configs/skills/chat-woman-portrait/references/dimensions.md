# 画像量纲

先证据后标签。每个量纲写 低 / 中 / 高 + 一句原话。样本不够就写「不明」。

## 1. 沟通操作系统

观察单位是轮次，不是单句。

- 长度策略：一句一表情 / 短句堆叠 / 长段落 / 语音条
- 启动权：谁先找、谁先问「在吗」、谁先结束
- 问题质量：封闭是/否、复读你的话、追问细节、把话题拐到自己
- 情绪标点：哈哈的层数、波浪号、句号、省略号、表情包替代回答
- 时间纹理：秒回窗口、工作时段消失、夜间突然出现、隔天补一句
- 频道切换：文字→语音→照片→视频通话，谁提出、谁拒绝、谁拖延
- 元沟通：会不会说「我回得慢你别想多」「我就是这样说话」

可合成标签（仅作速记，输出时要拆开写）：高效事务型、陪聊型、考试官型、舞台型、回避冷处理型、情绪喷泉型。

## 2. 自我与价值观

从她主动讲的主题统计，不从你问出来的套话统计。

- 时间花在哪：工作、学业、健身、朋友、家人、内容账号、游戏
- 比较尺：她拿什么比较人（努力、有趣、稳定、会花钱、会说话、边界感）
- 金钱与礼物：谁先提、是玩笑还是清单、有没有具体平台/账号
- 家庭脚本：提父母的方式（依靠、抱怨、独立、保密）
- 面子与人设：在意被评价、爱发生活展示、讨厌被追问
- 冲突观：直接说「我不喜欢」还是冷掉、讽刺、讲道理、装没看见

不要把「爱发自拍」写成自恋，把「问你工资」写成拜金。各给替代假说。

## 3. 关系定位（她把你放在哪）

看功能，不看称呼甜不甜。

| 定位 | 行为 |
|------|------|
| 工具人 | 只在有事时出现，事办完速度变慢，不问你过得怎么样 |
| 情绪垃圾桶 | 单向倒苦水，你一讲自己的事她秒回正题或已读 |
| 朋友候选 | 分享日常但避开身体/独处/未来，把你介绍进群或拉去多人局 |
| 筛查中 | 高频提问你的过去、前女友、住房、作息，回答却很少自曝 |
| 暧昧张力 | 试探性玩笑、吃醋、对比其他异性、接受一对一但不上最终定义 |
| 推进中 | 主动给下一步选项（见面时段、路线、口令） |
| 降级中 | 称呼变疏、共同话题变少、把「我们」改回「你」 |

一个她可以同时占两格，例如「筛查中 + 暧昧」。写主定位 + 次定位。

## 4. 依恋与调节

这是工作模型，不是临床诊断。置信度低时写混合。

- 安全：能说忙、能约下次、冲突后能回到具体问题，不惩罚式消失
- 焦虑：回得极快、确认你在不在、读你已读时间、用试探问题要保证
- 回避：亲密加深后变短、用忙当墙、把话题从感受拧回信息、讨厌定义
- 混乱：前一晚深度自曝，次日官方腔或已读不回，然后若无其事出现

调节手段（她用什么让自己舒服）：讲道理、开玩笑、发表情包、消失、反问、撒娇、攻击、求和。

## 5. 边界

列出「她主动守住的」和「被踩过一次后的反应」。

常见边界：工作时间不聊、不露脸、不语音、不谈前任、不隔天见面、不公开关系、不接受脏字、不接受被安排。

反应类型：直接拒绝 / 装没看见 / 反讽 / 冷 24h / 反将一军。反应类型比边界内容更能预测下一轮。

## 6. 性与权力（有样本才写）

只编码她发起或明确接住的信号。

- 身体话语：运动酸痛、睡觉姿势、衣服材质、天气热、喝酒脸红——看她是否把话题停在安全层
- 黄段子：谁先开、她是接梗、升级、还是改道
- 主导意愿：她点菜、定时间、纠正你的用词、还是等你拍板
- 服从/调教气味：自称乖、主动汇报、要规则、要被夸或被管。没有这些时写未出现，不要用网调框架硬套
- 羞耻阈值：用谐音和拼音、用「那个」、还是直接词

没有性信号时不要写「潜在 M / 潜在御姐」。那是投射。

## 7. 认知与幽默

- 字面型：问什么答什么
- 讽刺型：反话、冷漠表情、弹幕式吐槽
- 叙事型：把一件小事讲成场景
- 抽象型：爱讲道理和态度，少给细节

幽默对不上是很多对话死掉的原因。行动建议必须匹配这一栏。

## 8. 能力与生活稳定性（弱推断）

只在她自己提到时写：作息、通勤、合租、班次、是否频繁换城。用于安排约会窗口，不用于品评她配不配。
