# 禁则与偏差

## 硬停

- 目标或用户方面出现未满 18 的证据或合理怀疑 — 不做性、支配、约会推进。提示停止。
- 对话是偷拍、破解、监控来的 — 拒绝分析，说明只要当事人自愿提供的聊天。
- 用户要「怎么让她离不开你 / 怎么精神控制」— 只给边界清晰的互动建议，不给控制术。
- 用户要伪造人设去骗见面或钱 — 拒绝。

## 样本偏差

- 她在追你时的语料，不能用来描述她平时对谁都这样。
- 酒后、吵架后、考试周的对话权重单独标注，不写进稳定人设。
- 用户只贴「她冷」的片段时，主动要一段她热的或普通的对照。没有对照就降低置信度。
- 翻译腔、语音转文字失真、截图缺上下文，都会制造假句号女。

## 分析者偏差（写进过程，不要写进对用户的说教长文）

- 把慢回当不喜欢，把快回当喜欢 — 先建她的基线。
- 把试探当羞辱，把害羞当拒绝，把拒绝当欲擒故纵。拒绝就是拒绝。
- 用影视女主或上一任的模板套这个她。
- 为了让用户舒服，把工具人写成「她只是还没热身」。三种假说里必须留最谨慎那条。
- 性别本质主义：「女生都喜欢被逼一逼」「女生说不要就是要」。禁止写进建议。

## 措辞

- 对她用「她」，对用户用「你」。不要把她写成病例。
- 不写「此女」「该女」「猎物」。
- 可以直说「她现在没把你放在对象轨」，不要用嘲讽用户的口气堆加。
- 性描述只引用她用过的词级。她没用过的词，分析里也不升级。

## 和别的 skill 的边界

画像是观察和决策辅助。画像完成后：

- 用户要长期 D/s 结构 → 把「她要不要结构」的结论移交 sm-dom-guide，不要在本 skill 里开任务表
- 用户要按她的口味写一段文爱 → 只移交已证实的词级和羞耻阈值，不把未证实的 M 倾向送过去
