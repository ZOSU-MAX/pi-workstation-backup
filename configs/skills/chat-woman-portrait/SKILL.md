# Chat Woman Portrait

根据用户贴出的对话（截图转写、复制粘贴、分角色摘要）给目标女性做一份可更新的画像。默认分析对象是对话里的「她」。用户是分析发起人，不是被分析对象，除非她自己说「分析我」。

先读证据，再下判断。证据不足就标「样本不足」，不要编故事。

## Hand off

- 只问「什么是女人画像 / 怎么追」且没有对话样本 → 普通说明，不加载本 skill 的深模板
- 要布置网调任务、契约、周复盘 → `../sm-dom-guide/SKILL.md`
- 要直接开文爱、dirty talk → `../text-erotic-roleplay-kb/SKILL.md`
- 对话里出现明确未成年信号（自称中学生、家长管作业、未满18）→ 停止画像中的性/支配维度，只做安全提醒，不给撩拨或推进亲密的建议

## 输入处理

1. 分清角色。标出「用户 / 她 / 第三人」。角色不清先问一句再分析。
2. 记下渠道与阶段。微信/QQ/陌陌/探探/小红书/线下加的、认识多久、有没有见过面。没有就写未知。
3. 把对话切成轮次。关注谁先开口、谁收尾、谁改话题、谁提见面/语音/照片。
4. 区分一次会话和跨天关系。跨天要看冷热周期，不要用某一晚的热情覆盖一周的回避。
5. 样本门槛
   - 少于 8 轮有效来回 → 只出「初稿画像」，每条判断带置信度低
   - 只有她的单边截图 → 只分析风格，不判断她对用户的心意
   - 用户只给自己的发言 → 要求补她的原话，不猜

## 分析顺序（固定）

按这个顺序写，避免一上来就下「她喜欢你 / 她在玩你」的结论。

1. 沟通操作系统 — 怎么说话（分类读 `references/communication-styles.md`）
2. 自我与价值观 — 在乎什么
3. 关系定位 — 把你放在哪
4. 依恋与调节 — 靠近/推开的方式
5. 性与权力信号 — 仅在样本里出现时写，不要硬挖
6. 红绿旗与风险
7. 信息缺口
8. 行动建议 — 下一句、不要做的事、需要补采的问题

详细量纲读 `references/dimensions.md`。沟通操作系统分类读 `references/communication-styles.md`。中文聊天微信号读 `references/cn-chat-signals.md`。成稿格式读 `references/portrait-template.md`。偏见与禁则读 `references/caveats.md`。

每轮最多读 2 份 reference。默认先读 dimensions + portrait-template。沟通操作系统判断读 communication-styles。信号对不上再读 cn-chat-signals。用户质疑「是不是想多了」时读 caveats。

## 判断纪律

- 一条结论至少挂一条原话或行为（时间、长度、谁先提）。没有原话就标推测。
- 同一行为给两个假说。例：「已读不回 6 小时」= 忙 / 降优先级 / 在观察你，不要只写冷淡。
- 用区间，不用标签暴政。兴趣浓度写 0–10，并写「此刻」而不是「永远」。
- 文化默认按华语网聊。句号、呵呵、嗯嗯、语音条、拍一拍含义见信号表，不要用英语短信习惯硬套。
- 不把生理或星座当因果。用户自己提星座可以当她的自我叙事，不当人格证据。
- 不把「女性」写成统一策略。画像是这一个她，不是「女生都这样」。

## 兴趣浓度（此刻）

只根据对用户的行为打分，不根据她美或话多。

| 分 | 典型证据 |
|----|----------|
| 0–2 | 已读不回成习惯、只回问题不追问、把你推向别人、明确拒绝 |
| 3–4 | 礼貌短回、表情包应付、不开启话题、见面一拖再拖 |
| 5–6 | 有问有答、偶尔自曝、窗口期回复快、但很少主动 |
| 7–8 | 主动找、追问细节、分享当天、接受或提出下一步 |
| 9–10 | 打破自己的回复节奏来找你、引入私密、推动独处/语音/见面 |

分数旁边写「趋势」：升温 / 横盘 / 降温。趋势比单点分数有用。

## 输出

默认用中文，结构跟 `references/portrait-template.md`。用户要短评就出「五句话画像 + 下一句」；要完整报告就出全模板。

完整报告必须含：

- 一句话人设（20 字内，像给角色起外号，不要鸡汤）
- 沟通操作系统（从 `references/communication-styles.md` 选最接近的类型）
- 她把你放在哪（朋友 / 备选 / 正在筛 / 已有张力 / 对立）
- 兴趣浓度与趋势
- 依恋工作模型（安全 / 焦虑 / 回避 / 混合，标置信度）
- 边界清单（她守什么、踩什么会缩）
- 性与权力（有证据才写，否则写「样本未出现」）
- 红旗 / 绿旗各 2–5 条，都要原话
- 三种假说（最善意 / 最可能 / 最谨慎）
- 下一轮怎么回（给 2 个可直接发送的句子，语气匹配她的操作系统）
- 明确不要做的 3 件事
- 还缺什么证据

## 追问与迭代

用户补充新对话时，不要重写整份人设。只更新变化的维度，并写「本轮修正了什么」。把旧结论标成被推翻或被加强。

若用户要「针对她的回复稿」，先用本 skill 定人设，再写回复。回复稿必须符合她的节奏：她短你就短，她文学你才文学。不要用统一撩妹模板盖过去。
