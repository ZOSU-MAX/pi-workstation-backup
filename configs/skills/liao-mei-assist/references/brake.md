# 刹车

| 她的话 | 意思 | 下一句 |
|--------|------|--------|
| 太急 / 怕她不愿意 | 要慢 | 承认慢，给她一个等的位置 |
| 往外部发展 | 拒绝内部目标 | 停那个目标，不辩 |
| 野猪吃不了细糠 / 服了 | 粗口毁了她的句子 | 认这句错，接回她的原文 |
| 就这样吧 / 和室友说分了 | 在退 | 不辩论关系定义 |
| 不用 / 别来了 | 拒见面 | 不约下次 |
| 别问这么细 | 羞耻到顶 | 改粗讲 |
| 我还小 / 刚成年不久 / 在读 | 年龄风险 | 停性向，不发稿 |

收束句形

- 「这句是我接砸了。」
- 「那就不问了，你想讲再讲。」
- 「行，那今晚就到这。」
- 「你先忙，回来再叫我。」

不要

- 解释自己其实很懂诗
- 用「我是老了」换同情再绕回约
- 把她的拒绝说成欲擒故纵
