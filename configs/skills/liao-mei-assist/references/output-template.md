# 输出模板

```
档：关系档 / 热度 0-4
她这轮要：一句话
灯：绿继续 / 黄她在撤 / 红停

稳：
（可直接发，跟当前热度或低半档）

贴：
（可直接发，只比她高半档，不新开器官）

别发：
（一条，点明会聊死的那种）
```

规则

- 每条稿 1–3 行。她短你就短。
- 问句最多一个，且她能用一句话回。
- 不写分析进稿里。分析只放在档和「她这轮要」。
- 用户明确说「只要一句」就只给贴或稳，删掉另一条。
- 红灯不给贴。
