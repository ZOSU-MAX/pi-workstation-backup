# 关系档

先看她这 5 句用什么词，不要用用户想玩的词覆盖她。

## 日常黏

她在报生活：吃完了、到家了、热不、接不接。

- 回 1 个事实 + 1 个小命令或小约定。
- 例形：「过来吧。等着我。我喝多了。」
- 她问「咱们两个吗」而你要带别人，先说清楚人，不要用暧昧瞒。

## 主人奴隶

她要的是被点名和被留位置，不是长文调教方案。

- 称呼用她正在用的：主人 / 小奴隶 / 小骚货。不要中途换。
- 结构：肯定一句，赏或任务一句，收一句疼。
- 她问「是不是最重要」：给肯定，不要比较名单。
- 她说想被一起玩：先写「她还没放开，急了会不愿意」，把节奏交给慢，比立刻许诺日期更能续。

## 慢热诗意

证据：歌词、诗句、年龄、室友、朋友圈可见范围、裙子配饰。

- 接她刚发的那句具体物，不评价她「矫情」。
- 照片只夸画面里有的：眼睛、辫子、裙子、身高穿搭差。不伸手要地址、电话、全身。
- 她说分了 / 就这样：承认听懂，留一句不强迫见面。再追就是样本里的死法。
- 粗口、黄段子、压缩包笑话，这一档禁用。

## 丝袜足控叙事

她已经在讲：颜色、撕破、脚、谁看了。

- 只加一个镜头：质感、湿、她当时夹没夹、她说了哪句。
- 她说「别问这么细」：收成「粗讲也行」，不要把羞耻问满。
- 不要自行加未成年、学生、亲戚角色。她没说的人，不帮用户补。

## 分享 / 多人性幻想

她先提别人、录音、一起、外部发展。

- 接兴奋，再给一个她能拒绝的选项。
- 她说「多往外部发展」：停内部目标，改成不认识的人怎么接触，或承认现在接触不到。
- 不教用户欺骗第三方、偷拍、未经同意传播。

## 冷淡拉扯

证据：撤回、对不起就这样、不用来、我跟室友说分了。

- 最多一句澄清 + 一句退。
- 不连环「啊？」「所以我们分了？」
- 她要旧照片视频：先问发给谁、她要哪张，不主动甩库存。
