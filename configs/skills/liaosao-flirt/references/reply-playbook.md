# 回复零件

从这里改写，不要整段群发。每条稿只选一个零件组合：接原句 + 现场 + 可选问句。

## 首回零件

接原句

- 复用她的动词：洗、躺、热、睡不着、摸
- 复用她的空间：床、浴室、沙发、灯
- 点破反差：「骂色狼的人先把水擦干」
- 复用她的称呼：主人、小奴隶、小骚货（她叫你不要改）
- 短句直接型：复用她的短句（嗯、好、想要、不想、下面、摸摸）

现场（档 1）

- 温度、水、被子、空着的那一侧、手机屏幕亮着
- 「我这边也没关灯」比「我硬了」先出现
- 日常黏局：先报现场（开会、吃饭、喝多了），再给一个她能执行的小动作（下班回家、过来等我）
- 短句直接型：先报现场（在干嘛、看片），再给一个具体问题（哪里痒、有没有玩具）

现场（档 2）

- 手的位置、腿有没有并拢、呼吸、湿/硬只在她先用后跟
- 下一步用选择不命令：「今晚是只许想，还是许碰」
- 丝袜足控叙事：只追一个细节（谁、哪里、穿什么、她当时什么反应），连问三件她会羞停
- 短句直接型：问具体部位、具体动作（哪里痒、有没有玩具、你男人硬吗）

收尾问句（最多一个）

- 被子里还是被子外
- 左手还是右手
- 现在继续说，还是你先转个身
- 这句是写给今晚的，还是写给所有捡到的人
- 日常黏局：用她的称呼回，不要改人设
- 短句直接型：问具体问题（哪里痒、有没有玩具、你男人硬吗）

## 按类型的默认组合

夜床口嗨 = 接温度/姿势 + 半档身体 + 一个选择
婚内空窗 = 接空位画面 + 不审婚姻 + 不问住址
反差试探 = 点破 + 留台阶
主导发骚 = 跟词 + 短 + 让她点下一步
诱饵女号 = 接一句就停在瓶内 + 具体反问
树洞听者 = 接情绪，身体词不超过一个
互捕猎人 = 只打她设的那个钩
日常黏/主人奴隶 = 用她的称呼回 + 短 + 小安排（下班回家、过来等我）
丝袜足控叙事 = 只追一个细节 + 让她继续讲
分享/多人性幻想 = 先接她的兴奋 + 给一个可停的下一步
海角/群交幻想 = 给具体数字 + 她说怕就收成试试不行轮着来
短句直接型 = 短句回短句 + 主动问具体问题 + 逐步升级 + 表情互动 + 互相分享状态 + 图片交换

## 第二、三句

她接了具体问题 → 升半档，仍不索联系方式
她只回哈/嗯/表情 → 不要加码，换一个更具体的小问题，或收
她要微信 → 「今晚先聊完这张床」；用户坚持给联系方式时提醒黄灯
她主动器官词 → 可以跟，仍用选择题，不直接写插入过程
她说困 → 一句余韵结束，「醒了再捡」即可
她撒娇呼叫 → 用她的称呼回，不要改人设
她讲长故事 → 一次只挖一个洞，让她继续讲
她主动升档 → 你再升；她说太急 → 收成慢慢来
她问「什么时候才可以一起」→ 给「等以后有机会」
她说「又怕受不了」→ 「试试，不行就轮着来」
短句直接型：她回「嗯」「好」「想要」→ 短句回短句，主动问具体问题，逐步升级

## 扔瓶短钩库存（改细节再用）

档 1

- 赖床那一档，手机亮着的举个手
- 灯关了还是热，不是天气的事
- 空一侧有人回就行，没有也别劝我睡觉
- 日常黏：起床啦主人，有没有想你家小奴隶呀
- 短句直接型：在干嘛、看片吗、一个人？

档 2

- 写给同样睡不着的人，正经人请扔回海里
- 手闲着的话，先别急着回长句
- 今晚只想被说到撑不住，别报户口
- 丝袜足控：选一条喜欢的丝袜，露出骚奶子
- 短句直接型：想看吗、一个人吗、有没有玩具

不要扔

- 你好，我是男的，交个朋友
- 想不想看
- 有没有人约
- 复制来的长情书

## 女方口吻（用户是扔瓶或回瓶的女方）

同样短。她要的也是被读到，不是女号客服腔。

- 少用「哥哥呀~」万能甜
- 用现场换甜：「水还没干就看见你这条」
- 要筛人就设钩：「会接住温度的再回，报微信的不用来」
- 日常黏：主人主人呼叫主人，有没有想你家小奴隶呀
- 短句直接型：嗯、好、想要、不想、下面、摸摸
