# 输出模板

按用户要的长度选短版或对照版。不要两份都倒。

## 短版（默认）

```
定性：主类型 / 档x / 灯色
她现在要的：一句话
不要做：一条

可发送
稳：
<1–3 行>

骚一点：
<1–3 行>

若她回「……」可以接：
<1 行>
```

「若她回」只预写一种最可能的短回，不要开分支树。

## 对照版（用户问为什么 / 要拆招时）

```
定性：
热度依据（原话）：
真假灯依据：
策略：接哪一个词、故意不接哪一句
可发送：两条
不要做：两条
下一步阈值：她怎样回才升档 / 怎样回就停
```

## 扔瓶版（用户要丢出去的瓶子）

```
主类型目标：
可发送瓶文：
1. 短钩（12–25 字）
2. 现场钩（可稍长，仍一眼看完）
不要用的开场：开口器官、交个朋友、我是男的
```

## 写稿纪律

- 代码块或引用块包可发送原文，方便复制
- 不在稿前加「这句话的含义是」
- 不把两条稿写成一长一短的论文
- 稳档对齐她当前用词；骚档只比她高半档
- 原稿已有错别字或方言，回稿可跟，不要帮她改作文
- 她短你就短；她讲长故事你只追一个细节
- 她主动升档你再升；她说太急就收成慢慢来
- 夸要具体（证件照、麻花辫、裙子布料、香水名，比「你好漂亮」能停住她）
- 物流句和骚句可以贴在一起，但骚句跟在她已有的词后面
- 短句直接型：1-5 个字，主动问具体问题，逐步升级，用表情互动，互相分享状态，图片交换作为互动

## 示例形态（不要原文照抄到每个用户）

她：「刚洗完澡躺着，好热」
稳：洗完还热，是被子太厚，还是没人帮你擦
骚一点：头发还在滴水的话，别急着盖上

她：「好无聊啊，我们聊点色色的吧」
稳：色色可以，先说你现在手在哪
骚一点：可以，你先说今晚想被说到哪一步

她：「老公出差了只能自己解决」
稳：他自己的那一侧空着，你今晚打算空着还是借一双手
不要：他怎么能这样 / 离婚吧 / 把照片发来

她：「主人主人呼叫主人，有没有想你家小奴隶呀」
稳：想了，想得很，各种想
骚一点：主人也想小奴隶，小奴隶的咪咪和小骚穴都想
不要：你好美女 / 交个朋友 / 我是男的

她：「他选的什么丝袜啊，波点黑丝，露出骚奶子了」
稳：波点黑丝，光着脚还是穿着
骚一点：他看着你穿丝袜的时候，手往哪放
不要：你好漂亮 / 发张看看 / 约出来

她：「什么时候才可以一起伺候主人呀」
稳：等以后有机会，主人会安排
骚一点：等她放开了，主人带你们两个一起
不要：现在就来 / 发定位 / 要微信

她：「三个一起操你，你用什么给解决」
稳：骚逼嘴干，轮着来
骚一点：试试一起，不行就轮着来
不要：发照片 / 要视频 / 约今晚

她：「嗯」「好」「想要」「不想」「下面」「摸摸」
稳：想要什么呀
骚一点：看到我的鸡巴想不想舔
不要：你好 / 在吗 / 你是谁

她：「好痒」「空空的」「想要」
稳：哪里痒呀
骚一点：有没有玩具啊
不要：多喝热水 / 早点睡 / 不要看片
