# 瓶类型

先贴类型，再写稿。可多选，但要标一个主类型。没有原话就标不确定。

## 主类型

### 夜床口嗨

原话像「睡不着」「好热」「刚洗完澡」「下面有点」「想被抱一下」。时间多在 22:00 后。要的是当场有人把画面接住，不是简历和三观。

回法：接她的现场 + 一个具体触感 + 一个好答的选择题。不要问工作城市。

### 婚内/空窗发泄

「老公出差」「分居」「他不碰我」「一个人睡」。可能是真，也可能是高回复话术。先当故事接，不当婚恋咨询。

回法：不道德审判，不追问真名住址。把「空着的那一侧」写成今晚的画面。她若开始哭诉婚姻，降回档 0–1，不要继续加骚。

### 反差试探

白天装正经或树洞，夜里突然加一句身体。或先骂「漂流瓶都是色狼」再自己发骚。

回法：点破反差，但留台阶。「口是心非」可以，羞辱人格不行。

### 主导发骚

她先写器官、先要看、先下命令。不是害羞，是在筛能跟上的人。

回法：跟上用词，短，带一点被她点名的感觉。不要突然变小受，除非用户要受方口吻。也不要立刻抢主导变成网调。

### 诱饵女号

甜、勤、万能共鸣、三四句转微信/语音房/礼物/直播。头像网图、城市写「北京上海」，自我介绍像脚本。

回法：可玩半轮，但稿里不给微信号、不点链接。建议用户用一个具体、难套模板的问题筛（现在房间灯什么颜色、刚才那句是手打还是复制）。

### 引流/诈骗瓶

约炮 App、认证费、同城小姐、扫码看片、金币才能继续、裸聊后要挟。

回法：不写续撩。告诉用户停。见 `risks.md`。

### 树洞听者

加班、分手、失眠但无身体词。混在发骚海里，被当成炮文会翻车。

回法：先当听者。用户坚持要撩，只允许档 0 升到 1，并声明可能被扔回海里。

### 互捕猎人

瓶文本身就是筛人。「会聊的来」「别说你好」「能接住再回」。她在等一个不像群发的人。

回法：只接她设的钩子，展示你读过原话。展示阅读比展示骚更重要。

### 日常黏/主人奴隶

「主人主人呼叫主人」「有没有想你家小奴隶呀」「起床啦主人」。短句、日常安排、撒娇呼叫。可能是真瓶，也可能是已转私聊的续场。

回法：用她的称呼回，不要改人设。她叫主人，你不要突然叫宝宝讲人生。短、具体、带一个小安排（下班回家、过来等我）。物流句和骚句可以贴在一起，但骚句跟在她已有的词后面。

### 丝袜足控叙事

她在讲丝袜、脚、谁摸了、什么反应。长故事，男方只追一个细节。

回法：一次只挖一个洞（谁、哪里、穿什么、她当时什么反应）。连问三件她会羞停。让她继续讲，不要你单开新器官。

### 分享/多人性幻想

她主动提别人、一起、录音、三个人。先接她的兴奋，再给一个可停的下一步。

回法：她问「什么时候才可以一起」→ 给「等以后有机会」。她说「太急」→ 收成「慢慢来，你等」。不要一次拉满，她主动升档你再升。

### 海角/群交幻想

约多人、发骚逼照片、让他们看看。她问「你想约多少」→ 给具体数字。她说「又怕受不了」→ 「试试，不行就轮着来」。

回法：先接她的兴奋，再给一个可停的下一步。她短你就短，她主动升档你再升。

### 短句直接型（海角社区风格）

「嗯」「好」「想要」「不想」「下面」「摸摸」。短句为主，1-5 个字。主动引导，问具体问题（哪里痒、有没有玩具、你男人硬吗）。逐步升级，从日常到性话题。表情互动，经常使用表情回应。直接表达，不绕弯子。互相分享，双方都分享状态。图片交换，交换照片作为互动。

回法：短句回短句，主动问具体问题，逐步升级，用表情互动，直接表达，互相分享状态，交换照片作为互动。

## 次标签（可叠）

- 语音钩 — 声音是产品，文字是预告
- 闪照钩 — 3 秒图，真假都可能
- 同城钩 — 「附近」「就在这栋」；可能约真人也可能酒托
- 角色钩 — 老师、少妇、隔壁；当成人角色，不写未成年身份
- 惩罚钩 — 「敢回就怎样」；还没到网调，先当调情
- 日常黏钩 — 起床、吃饭、接你、热不热、想你；短句、撒娇
- 叙事钩 — 她在讲长故事，你只追一个细节
- 多人钩 — 她主动提别人、一起、录音、约多人
- 短句钩 — 1-5 个字，直接表达，不绕弯子
- 图片钩 — 交换照片作为互动

## 一句话判定格式

`主类型 / 热度档 / 真假灯`

例：`夜床口嗨 / 档2 / 黄灯偏真人`
例：`日常黏/主人奴隶 / 档1 / 绿灯`
例：`丝袜足控叙事 / 档2 / 绿灯`
例：`短句直接型 / 档2 / 绿灯`
