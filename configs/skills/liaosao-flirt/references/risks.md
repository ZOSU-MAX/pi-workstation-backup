# 风险灯

只用于判断停不停、稿里能不能续撩。不提供作案方法。

## 红灯 — 停，不代写续撩

- 约炮 App / 同城小姐 /「认证就能约」
- 要先充值、买会员、做任务、才能继续看她
- 扫码、下载陌生 App、开无障碍权限
- 裸聊过程中或结束后要钱，否则散播
- 快递到付名牌、酒托饭托指定地点高消费
- 对方或照片声称未满 18、在读初高中、家长管作业
- 对方或用户提到未满 18、初中、高中在读、学生证年龄对不上、刚成年几个月且语境暧昧

对用户只说：这是收割脚本，关掉，不要转账，不要再发私密件。不要帮他「再试探一句看是不是真的」。

## 黄灯 — 可聊，不导流

兼职女号与真人口嗨的重叠区：

- 头像网图、资料城市一线、自我介绍像复制
- 甜、勤、万能「哥哥你好暖」
- 3–5 句内要微信、QQ、语音房、礼物、打赏
- 问年龄用「二二」这种规避写法并立刻转平台
- 不回答具体问题，只回表情和夸奖
- 日常黏局里突然要语音房、礼物、直播链接
- 短句直接型里只回表情不回答具体问题

筛法（写进建议，不写进对她的第一句）

- 问一个此刻才能答的细节：灯、被子、手机拿哪只手、上一句哪个字是手滑
- 故意把她的原句改错一个词，看她会不会纠正
- 她要平台外联系 → 回「今晚先在这聊完」
- 她叫主人但立刻要微信 → 黄灯，不给联系方式
- 短句直接型：她只回「嗯」「好」不回答具体问题 → 黄灯，换一个更具体的问题筛

黄灯也可以是真人害羞。黄灯不是判决，是限制动作：不给微信号、不点链接、不发可识别照片。

## 同城见面

瓶里「就在附近」可能是真想见面，也可能是酒托。本 skill 不写今晚就出门的路线。若用户要见面，只给线上再确认的句子，并提醒公共场所、不预付、不跟去第二地点。

## 媒体

- 默认文字
- 闪照可另机录，当会外流
- 不建议用户用实名主号发脸、房间、工牌
- 不替用户向对方索取裸照作为「证明你是女的」
- 海角/群交幻想里要发骚逼照片 → 提醒会外流，不代写发图文案
- 短句直接型：交换照片作为互动 → 提醒会外流，不代写发图文案

## 法律现实（一行）

卖淫招嫖、敲诈、传播私密影像、对未成年人的性内容，都不是本 skill 的玩法。口嗨停留在双方自愿的成年文字。
