# Liaosao Flirt — 漂流瓶 / 暧昧撩

## 先定性再写稿

按这个顺序，不要一上来就给黄段子。

1. 渠道与介质 — 文字瓶 / 语音瓶 / 闪照 / 已转私聊
2. 她的瓶类型 — 见 `references/type-map.md`
3. 热度档 — 0 路人 / 1 试探 / 2 发骚 / 3 求操门口（本 skill 最高写到 2.5，3 交文爱）
4. 真假浓度 — 真人夜聊 / 兼职女号 / 引流诈骗 / 不确定
5. 用户目标 — 续上今晚 / 筛真人 / 加联系方式 / 只想口嗨 / 未知则默认「续上今晚、先不索联系方式」

样本门槛

- 只有一句瓶文、没有来回 → 出类型 + 两条首回 + 一条不要做
- 有 2–6 轮 → 出热度档 + 下一句 + 风险灯
- 她单边很长、用户零回复 → 只分析瓶，不写「她已经喜欢你」

## 漂流瓶操作系统（写稿时必须遵守）

匿名瓶不是微信好友。她同时可能开着十几条对话。你的句子要能在 3 秒滑动里被停下来。

- 首回 **1–3 行**，总字数优先 12–35 字。长文必死在未读里
- 先接她的画面，再加一点你的身体或现场，不要自我介绍简历
- 问句最多一个，且要好回答（今晚还是床上、左边还是右边），不要「你是哪里人啊做什么的」
- 她短你就短。她已经器官词了，你才可以器官词；她只写「好热」，你不要突然写插入
- 不要第一句要微信、要语音、要照片、要约见面
- 不要第一句「你好美女」「交个朋友」「我也寂寞」
- 语音瓶用文字回也可以。先点她声音里的具体东西（气音、笑、停顿），不要「声音好听」
- 同一套话术不要让用户对每个瓶群发。按类型改一个具体细节
- 她讲长故事你只追一个细节，连问三件她会羞停
- 她主动升档你再升；她说太急就收成慢慢来
- 夸要具体。证件照、麻花辫、裙子布料、香水名，比「你好漂亮」能停住她

## 热度匹配

| 档 | 她的证据 | 你怎么回 |
|----|----------|----------|
| 0 路人 | 天气、树洞、找人听 | 接情绪或一个具体画面，不性化 |
| 1 试探 | 洗澡、失眠、老公出差、好无聊、想被抱 | 身体接近 + 现场，不写插入 |
| 2 发骚 | 湿、硬、摸、睡不着下面、主动要色色 | 点她用过的词，加一个动作暗示和下一步选择题 |
| 2.5 门口 | 她问尺寸/想不想/语音自慰 | 本 skill 给门口句，要继续黄就声明交文爱库 |
| 3 开操 | 她已经在写插入 | 停本 skill，改走文爱 |

升档规则：她先加码你才加码。她回落你回落。用户说「她发骚你却太正经」才升半档，不要一次拉到插入。

日常黏/主人奴隶局的升档规则：

- 她短你就短，不要长篇说教
- 她主动升档你再升；她说太急就收成慢慢来
- 用她的称呼回，不要改人设
- 物流句和骚句可以贴在一起，但骚句跟在她已有的词后面

短句直接型的升档规则：

- 短句回短句，1-5 个字
- 主动问具体问题（哪里痒、有没有玩具、你男人硬吗）
- 逐步升级，从日常到性话题
- 用表情互动，经常使用表情回应
- 互相分享状态，双方都分享自己的状态和感受

- 用「哦」软化陈述句（「挺快哦」「69很舒服哦」）
- 自然提及伴侣（「我老婆」「你男人」）
- 用反问引导对话方向（「你之前没看过么」「你不给你男人吃鸡吧么」）

禁止无故用「爱你」「处对象」「以后一起」收尾。瓶局默认今晚有效，关系以后再说。
