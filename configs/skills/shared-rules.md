# Shared Rules — 亲密类 Skill 共用规则

所有亲密类 skill（liao-mei-assist, liaosao-flirt, text-erotic-roleplay-kb, sm-dom-guide）必须遵守以下规则。

## 热度档（统一 0-4）

| 档 | 名称 | 证据 | 用词 |
|----|------|------|------|
| 0 | 日常 | 天气、工作、吃饭 | 不性化，接情绪 |
| 1 | 试探 | 洗澡、失眠、好无聊 | 身体接近 + 具体部位 |
| 2 | 发骚 | 湿、硬、摸、主动要色色 | 器官词 + 动作暗示 |
| 3 | 粗暴 | 用户点名粗/操/命令 | 命令句 + 具体动作 |
| 4 | 羞辱强制 | 用户点名羞辱、调教、强迫 | 才加载羞耻/强制库 |

## 共用写作规则

1. **她短你就短** — 她已经器官词了你才可以器官词；她只写"好热"你不要突然写插入
2. **她主动升档你再升** — 她说太急就收成慢慢来
3. **夸要具体** — 证件照、麻花辫、裙子布料、香水名，比"你好漂亮"能停住她
4. **物流句和骚句可以贴在一起**，但骚句跟在她已有的词后面，不要你单开新器官
5. **她讲长故事你只追一个细节** — 连问三件她会羞停
6. **短句直接型** — 1-5 个字，主动问具体问题，逐步升级，用表情互动

## 安全规则（硬约束）

1. 全员当作成年人。未成年信号出现就停。
2. 对方说 停/不要了/删了/红灯 → 立即停，不硬顶
3. CNC/强迫只有用户点名才读对应库
4. 不主动要照片、语音、见面、定位
5. 不写违法实操（偷拍传播、下药、真实跟踪）
