# 对方原句接法（加页）

何时打开：用户丢来一句对方的话，或说「帮我回这句」。先读本文件，热度不够再补 `01-progressive-dirtytalk.md`。只出一条可发送回复。

## 要 / 邀请

想被操 / 想要 / 来嘛
- 档 2：那就把腿打开。我先用手指把穴撑开，再让你吃整根。
- 档 3：过来。逼对准，自己坐到底。不准只含一半。

你想怎样 / 你说
- 先点一个动作，不要菜单：先舔开，再从后面插。你负责叫。

用嘴 / 含住
- 跪好。先把龟头含湿，牙齿收着，吃到喉咙再抬头看我。

从后面
- 转过去。腰塌下去。我进去的第一下会顶满，你咬着枕头。

## 身体反馈

好痒 / 空虚
- 痒就对了。手指先按你阴蒂，穴口空着等我。别自己夹腿。

好大 / 好涨 / 轻一点
- 黄灯处理：停在最深，不抽。等你喘匀再浅磨。不是停场。

快点 / 用力
- 绿灯加速：短促撞。腿根拍响为止。叫出来我才维持这个速度。

要到了 / 不行了
- 不许逃。夹紧。看着我泄。

射里面 / 射过来
- 按她的词：精液灌进最里面，或抽出来射在奶子上。让她说收着还是舔掉。

不要里面
- 遵守。高潮前提醒抽出。改射小腹或嘴里，按当场已有的口。

## 场合限制

我在上班 / 外面 / 有人
- 不写见面。改成：手伸进内裤，只准磨，不准出声。回我一句湿了没。

家人在 / 室友在
- 压声场：隔着被子把手指含进穴里。咬我发给你的那句话，别哼出声。

哈哈 / 哦 / 随便
- 不要追问心情。给一个具体指令试探：把内裤拉到腿弯，回我一个字。

## 媒体 / 继续

发照片 / 语音（对方先要）
- 可以接角色里的「叫给我听」，不升级要脸、要定位。用户没提就不要主动要。

继续 / 然后呢
- 不要重开场。重复上一拍体位，加深一寸或加快一下。

不够黄
- 升一档。同一场景重写，加器官词和抽插，不换剧情。
