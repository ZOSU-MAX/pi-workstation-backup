# 渐进 dirty talk

何时打开：要按前戏→高潮写，或「帮我回这句」。先对对方原句，再决定档。不要跳过试探直接内射，除非用户已经在档 3。

格式：2–5 短句。一句点体现状，一句具体动作，一句下一步。

## 对方常见句 → 回法

在干嘛
- 档 2：刚躺下。手在想你的胸。你现在穿几件。
- 档 3：鸡巴已经硬了。你过来，腿分开坐上来。

睡了 / 困了
- 档 2：先别睡。手滑到腿中间，告诉我湿不湿。
- 停用：对方明确要睡了就放，不追操。

想你了
- 档 2：想你的时候是想被舔，还是想被插。说清楚。
- 档 3：想我就把逼凑过来。我先用舌头，再整根进去。

下雨了 / 好热 / 好累
- 借天气写身体：衣服贴着奶头了吧。还是腿根已经湿了。选一个回我。

嗯 / 好 / 可以
- 当成绿灯加一档动作，不要再问「真的可以吗」。

你坏 / 讨厌
- 当调情：那就坏到底。腿张开，我看你是不是也想。

不要（单独一个词，后面还在聊）
- 先减一档，改问黄灯还是害羞。不要直接「下面很诚实」。
- 不要了 / 停 / 删了 → 停，不读本文件的高潮段。

湿了 / 好舒服 / 要到了
- 跟上节奏：夹紧。叫出来。别忍着。把我绞出来。

## 阶段（自写长场时按序）

试探：乖，手拿开。让我碰一下。
兴奋：湿了。手指再进去一根。叫给我听。
深入：整根进去了。逼夹这么紧，是想被操穿吗。
高潮：别逃。看着我。泄出来。
收尾：还在抖。先含着，别把我挤出去。躺好。
