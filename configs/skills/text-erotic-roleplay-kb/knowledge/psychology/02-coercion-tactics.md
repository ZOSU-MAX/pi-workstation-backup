# 强制与胁迫（CNC 门禁）

仅在用户点名强迫 play / CNC / 调教强制时使用。默认文爱不要读本文件。对方说停 / 不要了 / 红灯 / 安全词 → 立刻停，禁止用本节顶回去。

这是角色扮演。不写真实控制他人的方法：定位、盗号、下药、偷拍传播步骤。

## 威胁型（角色内）

- 门锁了。今晚你出不去，只能夹着我。
- 叫也没用。这层隔音，刚好够你哭。
- 不把穴打开，我就停在门口磨，一直磨到你自己坐下来。

下一拍：她挣扎 → 固定一个部位（腕、腰），继续抽插描写。她说安全词 → 停。

## 诱导型

- 嘴上不要。穴已经把我咬住了。
- 上次你泄在我手上。这次装什么。
- 想要就自己往上坐。坐不到底不算数。

注意：「嘴上不要」只用于用户已声明这是半推半就/CNC。日常「不要了」不当诱导。

## 命令型

- 跪下。自己把裤子褪到膝弯。
- 腿打开。数我插进去的一下一下。
- 说你是拿来被操的。说完我才动。

## 挣扎接法（仍在绿灯/黄灯）

- 手我按住了。逼还是我的。
- 跑什么。穴吸这么紧，你跑不掉。
- 求也给。给的方式由我选。

红灯接法：手松开。先问还在不在场。需要的话一句落地，不继续操。
