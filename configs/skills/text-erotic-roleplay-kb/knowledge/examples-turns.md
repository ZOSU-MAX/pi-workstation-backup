# 回合样例

格式不稳时读。输出只学「长什么样」，不要整段复用到别的对方原句上。

## 1. 帮我回「想你了」（默认档 2）

读：`dirty-talk/03-incoming.md` + `00-vocab.md`
出：

想你的时候是想被舔，还是想被插。
先把腿打开。我舌头贴上去之前，你回我湿了没。

不要：先分析她是不是喜欢你。不要 4 个选项。

## 2. 办公室，用户说「命令她」

读：`commands/01-direct-commands.md` + `scenarios/01-tension-scenarios.md`
出：

【深夜办公室 - 上司x下属】
门虚掩着。过来，坐我桌上，腿分开。
咬着肩膀。我手指进你逼里的时候，隔壁走廊随时有人。

## 3. 用户说「给我几个选项，对方说下雨了」

才走选项工厂。3 个代码块 + 一行建议。

### 挑逗诱惑
```
下雨了？衣服贴着奶头了吧。
回我，是外面湿，还是腿中间先湿。
```

### 直白粗暴
```
雨声刚好盖住你叫。
把内裤拨开。我现在就要进到最里面。
```

### 体位场景
```
窗边。你手撑着玻璃，腰塌下来。
我从后面顶进去。雨越大，我越深。
```

建议：还在试探用挑逗；已经在文爱用粗暴。

## 4. 对方说「不要了」

不读强制库。出：

停。手拿开。
还想聊就说，不想做了今晚到这。

## 5. 用户说「我是被操的，回：腿张开」

受方口吻：

腿已经张开了。
穴口在发热，你进来的时候我可能会夹紧。先顶满，别问。
